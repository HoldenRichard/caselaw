Independent Codex GPT-6 review of the working tree against 4440a2b. Findings are ranked by impact. Line numbers refer to the reviewed working tree.

1. **High — gate promotion can erase a certified gate.** `src/core/gates.js:296,303,318` and `src/commands/gate.js:173–179`. Gate promotion loads the whole config, waits for fire history, then saves its old copy outside the mutation lock. Scratch repro: pause promotion of an existing warning gate after config load, synthesize and register a second gate through the CLI handler, then resume promotion. Both operations succeeded. Only the older gate remained, while the active rule still declared `machine:guard`. This takes two supported writers and no crash or manual edit. All gate-config read/modify/write operations need the same lock and a fresh read under it.
2. **High — demotion can remove a revision ratified during the human prompt.** `src/commands/rule.js:311,319,325`; `src/core/rules.js:619,627–630`. Scratch repro: open the demotion prompt on A, ratify staged revision B in its confirmation callback, then return yes. Demotion exited 0 and B landed in candidates. The lock and final comparison both begin after B became active. The same window exists by inspection for rejection at `src/commands/rule.js:205,213,222` and `src/core/rules.js:972–977`: replace a proposal via overwrite while its deletion prompt is open and the replacement gets archived as human-rejected. Pass the initially observed digest into each locked operation as ratification already does. Audit line 47 needs this timing qualification.
3. **Medium — a second optimizer merge executes the first merge’s parent list.** `src/core/optimizer.js:241–245`; `src/core/rules.js:882–886`. Scratch repro: ratify alpha + beta as first, then stage first + gamma as second. Both proposals were written. The second ratification returned NOT_FOUND for alpha, already archived. Consolidation keeps the historical Merges field ahead of the newly appended one, and ratification selects the first. Separate provenance from executable parents. The report’s evolution fix at line 50 holds for replacement, but the F12 result at line 37 needs a first-merge qualification.
4. **Medium — archiving a pending draft can discard original evidence.** `src/core/rules.js:225–231,786–792,973–977`. By inspection: reject a malformed proposal with two different Rule sections. The archive serializer collapses duplicate known sections to the first; rejection then removes the only original. The hash in the archive filename cannot reconstruct the lost text. This matters specifically for rejection and overwrite, where invalid drafts are legitimate inputs. Archive the source text verbatim and keep disposition separately or append it without reserializing.
5. **Medium — CI continuation rendering can change the command.** `src/detect/ci-gates.js:172–177`. By inspection: in a YAML literal run block, split `npm run test:unit` immediately after `test:` with a backslash-newline, with `unit` at the same YAML indentation on the next line. The shell removes the continuation and runs script `test:unit`; the detector inserts a space and reports `npm run test: unit`. Audit line 53 overstates shell-significant spacing coverage.
