## Original findings

1. **Promotion overwrote a concurrent registration — fixed for the inspected config writers.** Gate promotion reads, updates and saves under the common lock (src/core/gates.js:296–321). Synthesis and manual rule promotion reload config and recheck ID collisions inside it (src/commands/gate.js:172–180; src/commands/rule.js:461–479). Direct trigger guard insertion also reads and saves inside it (src/core/triggers.js:245–252). Contention can refuse one operation; a retry reads the latest config. No second lost gate-config update confirmed.
2. **Stale demote/reject approval — fixed for the original revision swaps.** Both handlers obtain the digest before prompting and compare under lock before acting (src/commands/rule.js:205–222,311–325; src/core/rules.js:619–620,974–976). Digests intentionally normalize BOM and line endings. Merge-parent approval is the separate case above.
3. **Second optimizer merge replayed its first parents — fixed on the optimizer merge/evolve path examined.** New proposals relabel inherited transition fields before adding current parents (src/core/optimizer.js:241–252). Evolution skips historical merge execution (src/core/rules.js:880–884). Readoption is the remaining path reproduced above.
4. **Duplicate sections lost on reject/overwrite — fixed for decodable UTF-8 drafts.** Both paths archive the source string as a prefix without serializing its sections. The non-UTF-8 case limits the byte-preservation claim.
5. **Literal split token gained a space — fixed for the original shell continuation.** The literal branch removes one terminal continuation slash and concatenates without inserting a space. The comment repro limits what can be claimed about general shell semantics.
