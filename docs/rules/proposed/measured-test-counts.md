# measured-test-counts

**Trigger:** Updating test counts in documentation or external materials.

**Rule:** Distinguish source definitions from executed tests, derive each count from its stated source, and rerun the self-claim check before reusing it.

**Origin:** 2026-11-05 resume refresh: claims.test.js caught stale methodology counts of 874 source cases and 400 named controls; recount found 875 and 401, while the passing runtime suite reported 881 tests and 404 named positive controls.

**Enforcement:** memory
