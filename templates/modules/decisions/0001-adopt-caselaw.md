# ADR 0001: Adopt caselaw for AI-assisted development

**Status:** Accepted
**Date:** {{ today }}

## Context

This project uses AI coding agents. They are fast and confident, and neither
property is correlated with correctness. Two specific gaps prompted this:

1. Nothing written down said what an agent **cannot** verify here, so the
   handoff of unverifiable claims back to a human was implicit and therefore
   inconsistent.
2. Process knowledge lived in whoever remembered it. A rule enforced by memory
   degrades silently and gives no signal when it stops being followed.

## Decision

Install caselaw. Concretely, this project now keeps:

- `docs/authority-split.md` — what the agent can and cannot verify, with
  untested boundaries dated and scheduled for re-test.
- `docs/rules/` — case law, mined from this project's own incidents. Empty at
  install; a rule is only legitimate if it cites the incident that proved it.
- `docs/close-out.md` — a session close-out that asks, every time, whether this
  session earned a rule.
- `.caselaw/gates.json` — machine checks, promoted from rules that kept being
  violated.

## Alternatives considered

- **Nothing, keep it in our heads.** Rejected: this is what produced the gap.
  It also does not survive a new contributor or a context reset.
- **A static rules file copied from a template.** Rejected: rules that arrive
  without an incident behind them are someone else's superstition, and nobody
  enforces a rule they cannot trace.
- **Only CI checks, no prose.** Rejected: the interesting failures are the ones
  a check cannot express. Prose covers those; gates cover what is mechanical.

## Consequences

Costs accepted knowingly: a session close-out is extra work, `docs/` grows, and
the audit will nag about boundaries that go untested.

What it buys: the handoff of unverifiable work becomes explicit, rules
accumulate from real incidents rather than opinion, and the ones that keep being
violated become checks that cannot be forgotten.

The number to watch is days-to-first-ratified-rule. If `docs/rules/active/` is
still empty in a month, the proposing path is too hard and that is the thing to
fix — not this decision.
