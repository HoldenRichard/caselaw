# Glossary

The exact words this project uses in code, commits, copy, and pull requests.

This is **descriptive, not aspirational**: it records what the code actually
says today. Where a term and the code disagree, that is a defect — log it in
`known-issues.md` rather than quietly documenting the aspiration here.

Why it earns its place: an agent that does not know your vocabulary will invent
a plausible synonym, and a codebase with two words for one concept costs
everybody who reads it afterwards.
