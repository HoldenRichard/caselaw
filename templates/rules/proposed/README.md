# Proposals waiting for a human

Nothing in this directory is in force.

An agent drafts a rule here when something went wrong with a root cause it can name
(`caselaw rule propose <name>`). A human reads each one and ratifies it into `../active/`
(`caselaw rule ratify <name>`) or rejects it (`caselaw rule reject <name>`). Agents write here;
agents never move things out.
